 ## Hangman Game

## Project Description

-This is a simple text-based Hangman game developed using Python.
-The player has to guess a hidden word one letter at a time. The game allows a maximum of 6 incorrect guesses.

## Features

- Uses 5 predefined words
- Selects a random word using the 'random' module
- Allows the player to guess one letter at a time
- Displays correctly guessed letters
- Counts incorrect guesses
- Allows a maximum of 6 incorrect guesses
- Displays "Congratulations" when the player guesses the word
- Displays "Game Over" when the player reaches 6 incorrect guesses
- Runs completely in the console

## Technologies Used

- Python

## Python Concepts Used
- Random
- Lists
- Strings
- While loop
- If-else statements
- User input

## How to Run
1. Open the project in Visual Studio Code.
2. Open `hangman.py`.
3. Run the program.
4. Enter one letter at a time when prompted.
